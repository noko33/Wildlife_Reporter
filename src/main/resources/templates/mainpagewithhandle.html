This is a CS411 Project called the Wildlife Reporter that was created by Nathan Colunga, Ryan Choi, and Yunqi Han.

 

 

Query Notes

The Query page can be accessed above and is used to query in very basic queries where the user only wants to determine matching information of a species or information within a bound.

 

New Report Notes

The New Report page allows the user to add a new Report to the database. Unless the user is logged in and determined to be a verifier then the report will be submitted as unverified.

 

Advanced Queries Notes

This button allows the user to query with our premade advanced queries.

 

Map Notes

This button will allow the user to access our interactive map which will show the location of the reports on a map.

 

Log In/Log Out

This button will allow the user to go to the log in page if they are logged out and immediately log out if they are logged in. On the log in page they may also create a new account if they did not have one previously.
